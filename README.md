# เปรม นมสด - Landing Page

เว็บไซต์ Landing Page ทางการของร้าน **"เปรม นมสด"** ออกแบบและพัฒนาเพื่อนำเสนอข้อมูลร้าน เมนูอาหาร และบรรยากาศสุดชิลล์ยามค่ำคืน

---

## 🌟 จุดเด่นของหน้าเว็บไซต์ (Key Features)

1. **Brand Identity & Vibe:**
   - โทนสี Night Hangout ผสมผสานไฟปิงปองสีวอร์มไวท์ (Fairy Lights) และสีฟ้าของแบรนด์
   - ใช้ฟอนต์ Google Fonts ภาษาไทย (`Prompt` สำหรับเนื้อหา และ `Kanit` สำหรับหัวข้อ)

2. **Real-Time Store Status:**
   - ระบบตรวจจับเวลาเปิด-ปิดร้านอัตโนมัติ (17:00 - 22:00 น.) พร้อมแสดงไฟสัญญาณกระพริบสดๆ บนแถบสถานะและกล่องข้อมูล

3. **Signature Chalkboard Menu:**
   - ถอดแบบและจำลองป้ายกระดานดำหน้าร้านจริงที่เขียนด้วยชอล์ก พร้อมแสดงราคาซิกเนเจอร์ (นมสด 20/25/30, อิตาเลียนโซดา 25, ปังปิ้ง 12)

4. **Interactive Menu Grid & Filters:**
   - แยกหมวดหมู่เมนู: ขนมปังปิ้ง & ปังเย็น, นมสด & เครื่องดื่ม, ของทานเล่นทอดกรอบ, อิตาเลียนโซดา
   - แสดงรูปถ่ายจริงครบทุกเมนู พร้อมป้ายราคาและป้ายการันตี (Best Seller, Signature, Popular)

5. **Smart Budget Calculator ("คำนวณงบกินฟิน"):**
   - ผู้เข้าชมสามารถคลิกเลือกเมนูเพื่อจำลองสั่งและคำนวณราคายอดรวมแบบเรียลไทม์ แสดงให้เห็นถึงความคุ้มค่าสบายกระเป๋าของร้าน

6. **Interactive Google Maps & GPS Navigation:**
   - แผนที่ Google Maps แบบฝังบนหน้าเว็บ (Interactive Iframe) แสดงพิกัดจริง ณ ถนนจิระ อ.เมืองบุรีรัมย์
   - ปุ่มเปิด Google Maps นำทาง (Directions GPS) ไปยังร้านได้ทันที
   - ปุ่มเปิดดูหมุดบน Google Maps และปุ่มคัดลอกที่อยู่ลง Clipboard

7. **Real Clickable Social & Contact Channels (เชื่อมต่อไปยังเว็บ/แอปจริง):**
   - **Facebook:** ลิงก์ตรงค้นหาเพจร้าน และปุ่มทักแชทผ่าน Facebook Messenger (`m.me`)
   - **LINE:** ปุ่มทักแชทสั่งอาหารล่วงหน้า (`line.me/R/msg/text/...`) และปุ่มแอดเพื่อน LINE Official
   - **โทรศัพท์:** ปุ่มโทรออกทันที (`tel:0898495521`, `tel:0812345678`)
   - **Instagram & TikTok:** ลิงก์ไปยังแท็กและคลิปรีวิวร้าน
   - **Food Delivery:** ลิงก์ตรงสู่แพลตฟอร์มสั่งอาหาร LINE MAN, GrabFood และ ShopeeFood
   - **Floating Quick Contact Bar:** แถบปุ่มลอยด่วนมุมขวาล่างของจอ ให้ผู้ใช้งานโทร แชท LINE เปิด Facebook หรือนำทางได้ตลอดเวลาจากทุกจุดของหน้าเว็บ

8. **Ambiance Gallery & Lightbox:**
   - รวมภาพถ่ายบรรยากาศจริงของร้าน ทั้งมุมแสงไฟใต้ร่มไม้, โต๊ะสังสรรค์กลุ่มเพื่อน, งานศิลปะชอล์ก Your Name, และแก้วสังกะสีโบราณ
   - คลิกเพื่อดูภาพขยายแบบ Lightbox Modal ได้ทุกรูป

9. **Responsive Design:**
   - รองรับการแสดงผลทุกขนาดหน้าจอ ทั้งมือถือ (Smartphone), แท็บเล็ต (Tablet) และคอมพิวเตอร์ (Desktop)

## 🚀 วิธีการเปิดดูเว็บไซต์ (How to Open)

1. ดับเบิ้ลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้ (Google Chrome, Safari, Microsoft Edge, Firefox)
2. หรือใช้ Local Server เช่น Live Server ใน VS Code หรือคำสั่ง:
   ```bash
   python3 -m http.server 8000
   ```
   แล้วเปิดบราวเซอร์ที่ `http://localhost:8000`
